# Shared Household Chores - Rotating Schedule (ChoreWheel)

## 1. Overview
A lightweight tool for roommates/households to manage shared chores with automatic weekly rotation and completion tracking.

## 2. Core Features (Selected 3 Features)
1. **Chore & Household Member Management**: Define household members and chores with frequency (e.g., weekly) and effort weight.
2. **Automated Weekly Rotation**: Automatically assigns chores to members in a round-robin schedule each cycle.
3. **Completion Check-in & History**: Members check off completed tasks; system logs completion timestamp and tracks streaks/history.

## 3. Tech Stack
- **Framework**: Python 3.12+, Django 5+
- **Database**: SQLite (default for development)
- **Package Manager**: uv
